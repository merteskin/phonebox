Pages

Each page is a 12 × 6 grid of widgets. Pick a page on the left, arrange its widgets on the phone below and set their options. Drag pages to reorder them; the first one is the home page the panel returns to when idle. On the phone, swipe, use the volume keys, or tap the dots (or long-press a page) for an overview of all pages.

Shortcuts

The keys shown by Shortcut grid and Big button widgets. Click a key to edit it, drag to reorder. The phone only sends the key's id; commands never leave this computer.

Rules

Let the panel react to what happens on this computer: show the AI page when Claude needs you, the music page when something plays, an "on air" sign during calls. A rule fires when its condition starts; with only while it lasts the phone goes back to where it was (and a pushed value is removed) when the condition ends.

Claude Code permission prompts

When Claude Code asks for permission (run a command, edit a file…), the phone shows the request with Allow and Deny. If the phone is not connected or nobody answers in time, Claude Code asks in the terminal as usual. This needs a small hook in ~/.claude/settings.json; PhoneBox adds it for you (a backup is kept next to the file).

Wi-Fi & Tailscale

Let the phone connect without the USB cable

Pairing happens over USB: after turning this on (and restarting), plug the phone in once. The phone then talks HTTPS to this PC, trusts only this PC's certificate and has to present a secret key. The phone and this PC must be on the same network — or both on Tailscale, which also works from another place or across separate Wi-Fi networks. Windows Firewall asks once — allow it (tick the network type Tailscale uses, too).

Updates

Install new releases automatically

Checks on GitHub every 6 hours. The phone app is installed over USB without a prompt on the phone; the agent replaces its own files and restarts.

Webhooks

Push data into the panel from scripts, CI jobs, Home Assistant, cron … Values show up in Pushed value widgets (key = the last part of the URL), notifications in a toast on the phone and in the Notifications widget. Values survive restarts.

Examples

JSON payloads may carry value, title, sub, unit, icon, color, level (ok / warn / error), progress (0–1 or 0–100), items (a list) and ttl (seconds). Plain text or a number works too. Notifications take title, text, level, vibrate, seconds, wake (light up the night screen) and page (switch to it).
